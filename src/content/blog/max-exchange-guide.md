**MAX 交易所**是台灣最老牌的加密貨幣交易所之一，成立於 2018 年，會員數超過百萬。如果你想用台幣買加密貨幣，MAX 是最常見的選擇之一。

這篇 MAX 交易所教學會告訴你：如何註冊 MAX、如何用台幣入金、如何購買 USDT 或比特幣，以及使用 MAX 要注意什麼。

## MAX 交易所是什麼？

MAX 交易所（MaiCoin MAX）是由 [MaiCoin 集團](https://www.maicoin.com/) 經營的加密貨幣交易平台，總部位於台北。

### MAX 交易所基本資訊

| 項目 | 內容 |
| :--- | :--- |
| 成立時間 | 2018 年 |
| 總部 | 台灣台北 |
| 支援幣種 | BTC、ETH、USDT、USDC 等 30+ 種 |
| 入金方式 | 銀行轉帳（台幣） |
| 手續費 | 掛單 0.05%、吃單 0.15% |
| 實體門市 | 台北市中正區（可現場開戶） |

### MAX 的優缺點

**優點**：
- 台幣入金方便（銀行轉帳）
- 有實體門市，可以現場諮詢
- 用戶數多，流動性好
- 有信託保管機制

**缺點**：
- 幣種選擇比國際交易所少
- 介面設計稍舊
- 部分進階功能需要較高等級認證

## MAX 交易所開戶教學

### Step 1：註冊帳號

1. 前往 [MAX 官網](https://max.maicoin.com/)
2. 點擊「註冊」
3. 輸入 Email 和密碼
4. 收取驗證信，點擊連結完成註冊

### Step 2：完成身分驗證（KYC）

MAX 有三個認證等級，建議至少完成 Lv2：

| 等級 | 需要資料 | 功能 |
| :--- | :--- | :--- |
| Lv1 | 手機號碼 | 僅能看盤 |
| Lv2 | 身分證 + 自拍 | 台幣入金、交易 |
| Lv3 | 銀行帳戶驗證 | 大額交易 |

**驗證流程**：
1. 登入後點「帳戶」→「身分驗證」
2. 上傳身分證正反面照片
3. 上傳手持身分證自拍照
4. 等待審核（約 1-3 個工作天）

### Step 3：綁定銀行帳戶

完成 Lv2 認證後，需要綁定銀行帳戶才能入金：

1. 點「錢包」→「新台幣」→「設定銀行帳戶」
2. 選擇你的銀行，輸入帳號
3. 系統會顯示一組「虛擬帳號」，之後入金就是轉帳到這個帳號

## MAX 交易所入金教學

### 台幣入金步驟

1. 登入 MAX，點「錢包」→「新台幣」
2. 記下你的「專屬虛擬帳號」
3. 用網銀或 ATM 轉帳到該虛擬帳號
4. 等待約 10-30 分鐘，台幣餘額就會到帳

### 入金注意事項

> ⚠️ **重要**：轉帳的銀行帳戶，必須是你在 MAX 綁定的那一個。用其他帳戶轉帳會被退回。

- 最低入金金額：100 元台幣
- 入金手續費：0 元（銀行端可能收跨行轉帳費）
- 到帳時間：通常 10-30 分鐘，假日可能延遲

## 如何在 MAX 購買加密貨幣？

入金完成後，你就可以用台幣購買加密貨幣了。

### 購買 USDT（推薦新手先買這個）

1. 點上方選單「交易」
2. 選擇交易對「USDT/TWD」
3. 在右側「買入」區塊輸入金額
4. 選擇「市價單」（立即成交）或「限價單」（指定價格）
5. 點「買入 USDT」

### 購買比特幣

1. 選擇交易對「BTC/TWD」
2. 其餘步驟同上

### 手續費說明

MAX 的手續費採分級制度：

| 類型 | 手續費 |
| :--- | :--- |
| 掛單（Maker） | 0.05% |
| 吃單（Taker） | 0.15% |

如果你持有 MAX Token（MAX 平台幣），可以折抵手續費。

## 如何從 MAX 提領加密貨幣？

如果你想把 USDT 轉到其他交易所（例如幣安），操作如下：

1. 點「錢包」→「USDT」→「提領」
2. 輸入目標交易所的「充值地址」
3. 選擇正確的網路（**TRC20 手續費最低**）
4. 輸入提領數量
5. 完成雙重驗證，確認提領

> ⚠️ **警告**：網路（TRC20、ERC20）一定要選對，選錯會導致資產永久遺失！

## 如何從 MAX 提領台幣？

如果你想把錢領回銀行帳戶：

1. 把加密貨幣賣成台幣
2. 點「錢包」→「新台幣」→「提領」
3. 輸入提領金額
4. 確認後，通常 1-2 個工作天會入帳

## MAX 交易所安全嗎？

### 安全措施

- **信託保管**：用戶的台幣資產由凱基銀行信託保管
- **冷錢包存放**：大部分加密貨幣存放在離線冷錢包
- **雙重驗證（2FA）**：支援 Google Authenticator

### 風險提醒

雖然 MAX 是台灣最大的交易所之一，但加密貨幣投資本身有風險：
- 不受存款保險保障
- 市場波動可能導致虧損
- 需自行保管好帳戶密碼和 2FA
